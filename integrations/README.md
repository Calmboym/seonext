# integrations/

Adapters for external providers: LLM, search, SERP, SEO APIs, crawling, analytics. See `docs/20_PROJECT_STRUCTURE.md` §3, §18-22 and `docs/07_TECHNICAL_ARCHITECTURE.md` §12.

Empty at `PHASE-0` by design — no external provider integration is foundation-level scope (`PHASE-0.1`–`.8` cover repo/env/DB/API/auth-mechanism/frontend-shell/observability/testing only). Populated in later phases once a specific provider integration is authorized.
